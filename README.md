# 💰 财富自由 · 现金流游戏

> 从老鼠赛跑到财富自由，你能走多远？

基于罗伯特·清崎《富爸爸穷爸爸》财商教育理念的纯前端现金流游戏。掷骰子、买资产、跳出老鼠圈、实现财务自由。

**🎮 [在线体验](https://你的用户名.github.io/cashflow-game)**（部署后替换此链接）

---

## ✨ 特色

- **零依赖** — 单个 HTML 文件，CSS / JS 全部内联，浏览器打开即玩
- **5 档收入层级** — 低收入到高收入，45+ 种真实职业可选，参数可自定义
- **40 格棋盘** — 老鼠赛跑圈 + 快车道，掷骰前进，触发事件
- **资产系统** — 房产、股票、生意、土地、黄金、基金、债券，买进卖出
- **进度可视化** — 被动收入 vs 总支出实时对比，进度条直观展示
- **存档接续** — localStorage 存档，关闭浏览器不丢进度
- **数字动画** — 金额变动带缓动动画，一眼看出哪个数字在变
- **结束海报** — 通关或破产时生成数据总结海报
- **彩蛋** — 长按标题触发隐藏机制

## 🎯 游戏目标

让你的**被动收入（非工资收入）**超过**总支出**，跳出老鼠赛跑圈，进入快车道，最终买下你的梦想。

## 🕹️ 玩法

1. **选择职业** — 从 5 个收入等级、45+ 种职业中选择，或自定义薪资/支出/子女数
2. **掷骰前进** — 每轮掷骰，走到对应格子触发事件
3. **抓住机会** — 遇到投资机会时，用现金购买能产生被动收入的资产
4. **控制支出** — 生孩子、购物、市场波动都会影响你的现金流
5. **实现自由** — 当被动收入 ≥ 总支出时，你就能跳出老鼠圈

## 🚀 部署

### 方式一：任意静态服务器

```bash
# 放到 Nginx/Apache 的 www 目录即可
cp index.html /var/www/html/
```

### 方式二：Python 快速启动

```bash
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

### 方式三：GitHub Pages

```bash
# 1. 创建仓库 cashflow-game
# 2. 上传 index.html
# 3. Settings → Pages → Source: main → Save
# 4. 访问 https://你的用户名.github.io/cashflow-game
```

### 方式四：Netlify

直接拖拽 `index.html` 到 [app.netlify.com/drop](https://app.netlify.com/drop)，3 秒上线。
